================================================================
  抖音评论区 — 指定用户发言抓取工具 使用说明
================================================================

【功能简介】

  输入一个抖音视频链接 + 要查询的用户标识，工具会自动抓取该视频评论
  区中这些用户的所有发言，包括：
    - 评论文字内容
    - 评论中的图片（如果有的话）
    - 评论中的表情贴纸（如果有的话）
    - 每条评论的点赞数
    - 评论发布时间
    - IP属地

  结果会保存为两种格式：
    1. JSON文件（结构化数据，方便程序处理）
    2. TXT文本报告（人类可读，方便直接查看）


【支持的用户标识（三选一即可）】

  你可以用以下任意一种方式指定要查找的用户：

    1. 抖音号 — 用户主页 @后面的那个（如 "zhangsan123"）
    2. UID — 纯数字ID（如 "60678995364"）
    3. 昵称 — 显示名称（如 "张三"）

  大小写不敏感，建议优先使用抖音号（最精确）。


【支持的输入格式】

  可以直接粘贴抖音APP里"转发→复制链接"得到的内容，不需要手动提取URL！
  支持以下所有格式：

    - 完整分享文案: "0.53 复制打开抖音，看看【xxx】的作品... https://v.douyin.com/xxxx/ g@b.Ag..."
    - 短链接: https://v.douyin.com/xxxx/
    - 标准链接: https://www.douyin.com/video/7441559247486733594
    - 纯视频ID: 7441559247486733594

  工具会自动解析并提取视频ID。


【使用前准备】

  1. 安装 Python（3.9 或以上版本）
     如果电脑上没有 Python，请去 https://www.python.org/downloads/ 下载安装
     安装时记得勾选 "Add Python to PATH"

  2. 安装 Playwright 浏览器驱动
     打开命令提示符（Win+R 输入 cmd），依次运行：

       pip install playwright
       python -m playwright install chromium

  3. 把本工具的所有文件放在同一个文件夹里


【快速开始（3步）】

  第1步：编辑 names.txt 文件
    用记事本打开 names.txt，每行写一个你要查询的标识（抖音号/UID/昵称），例如：
      zhangsan123
      60678995364
      李四

  第2步：运行工具
    在文件夹中双击 main.py（或打开命令行进入该文件夹，运行）：
      python main.py

  第3步：按提示操作
    - 直接粘贴从抖音APP复制的分享链接（含文案也没关系）
    - 按回车确认查询目标
    - 浏览器窗口会自动打开，如果要求登录，用抖音APP扫码即可
    - 等待工具自动抓取完成


【命令行模式（进阶用法）】

  直接指定参数，无需交互：

    python main.py --url "https://v.douyin.com/xxxx/" --ids "zhangsan123,李四"

  也可以粘贴完整分享文案：

    python main.py --url "0.53 复制打开抖音...https://v.douyin.com/xxx/..." --ids "张三"

  从文件读取目标：

    python main.py --url "https://v.douyin.com/xxxx/" --ids-file names.txt

  使用无头模式（不显示浏览器窗口）：

    python main.py --url "..." --ids "..." --headless


【结果文件】

  抓取完成后，在 output/ 文件夹中会生成两个文件：
    results_日期时间.json  — 完整结构化数据

  文本报告示例:

【注意事项】

  1. 首次使用需要登录
     工具会打开真实浏览器窗口，显示抖音视频页面。
     如果页面要求登录，用抖音APP扫描屏幕上的二维码即可。
     登录状态会被保存，以后再用就不需要重新登录了。

  2. 不要关闭浏览器窗口
     工具运行期间会自动打开一个浏览器窗口，不要手动关闭它。
     工具会自动滚动评论区加载数据，完成后自动保存结果。

  3. 网络环境
     需要使用国内网络，部分海外IP可能被抖音限制。

  4. 关于抖音号
     抖音号就是用户主页上 @后面的那个标识，不是所有用户都设置了抖音号。
     如果用户没有设置抖音号，可以用他的 UID（数字ID）或昵称来匹配。
     UID 可以从用户主页链接中找到（/user/后面的数字）。

  5. 抓取数量限制
     工具默认会尽可能多地抓取评论（自动滚动直到没有新评论）。
     对于百万级评论的热门视频，可能需要较长时间。

  6. 评论中如果有图片或表情贴纸
     工具会提取图片的URL链接，可以直接在浏览器中打开查看。
     图片文件本身不会下载，只保存链接地址。


【常见问题】

  Q: 运行时提示 "Playwright 未安装"？
  A: 请在命令行中运行: pip install playwright && python -m playwright install chromium

  Q: 粘贴分享文案后提示"无法识别输入格式"？
  A: 请确认粘贴的内容中包含 https://v.douyin.com/ 开头的短链接，
     或者直接粘贴纯短链接/标准视频链接。

  Q: 浏览器打开了但没反应？
  A: 检查是否弹出了登录窗口，需要扫码登录。如果页面加载很慢，可能是网络问题。

  Q: 抓取到的评论数量很少？
  A: 评论区是懒加载的，需要滚动才会加载更多。工具已内置自动滚动功能，
     如果仍然很少，可以尝试在 config.py 中调大 MAX_SCROLL_ATTEMPTS 参数。

  Q: 匹配不到指定用户？
  A: 请确认：
     1. 抖音号/UID 拼写正确（大小写不敏感）
     2. 用户确实在该视频下留过言
     3. 如果用的是昵称，注意多人可能同名，建议改用抖音号或UID

  Q: 如何找到某个用户的抖音号或UID？
  A: 进入该用户的抖音主页 → 查看 @后面的就是抖音号，
     主页链接 /user/ 后面的数字就是 UID。

  Q: 短链接能用吗？
  A: 完全可以！直接把APP里复制的分享文案原样粘贴进去就行。


【文件说明】

  main.py           — 主程序入口
  crawler.py        — 爬虫核心逻辑
  config.py         — 配置参数（可自行调整超时、滚动等设置）
  output.py         — 结果处理和文件输出
  names.txt         — 目标列表（可填入抖音号/UID/昵称，一行一个）
  requirements.txt  — Python 依赖声明
  browser_data/     — 浏览器登录态数据（自动生成，不要手动删除）
  output/           — 抓取结果输出目录（自动生成）


【技术原理简述】

  本工具使用 Playwright 控制真实的 Chrome/Chromium 浏览器，打开抖音视频
  页面，拦截页面加载过程中自然发起的评论区API请求，直接获取服务器返回的
  结构化JSON数据。这种方法不需要逆向破解抖音的加密签名参数，因此维护成本
  低，不容易失效。

  核心流程：
    解析分享文案 → 提取短链接 → 浏览器跟随重定向 → 获取视频ID
    → 滚动评论区 → 拦截评论API响应 → 提取文字/图片/贴纸/点赞数
    → 按抖音号/UID/昵称匹配 → 生成报告
